# vpnsplit

Раздельное туннелирование для Windows: выбранные приложения ходят через
VPN, всё остальное — обычным путём. Приложению можно назначить своё
подключение: одному — рабочий VPN, другому — зарубежный.

Программа ранняя. Она написана под нужды автора, проверена на одной машине
и может не подойти к вашей сети или вашему VPN. Windows 10/11, x64.

При создании программы использовался ИИ.

## Что умеет

- **Список приложений.** Обычные программы и приложения из Microsoft Store;
  приложение ведётся вместе со всеми программами, которые оно запускает.
- **Свои подключения OpenVPN.** Служба сама держит подключения по вашим
  `.ovpn`: поднимает при запуске Windows и возвращает после обрыва.
  Понимает ключ под паролем, вход по логину и паролю и одноразовый код
  (его программа спрашивает при каждом подключении).
- **Каждому приложению — своё подключение.** Внутренние адреса и имена
  рабочей сети получают только приложения рабочего подключения; маршруты и
  DNS, которые сервер велит поставить всей машине, не применяются.
- **Отказ вместо утечки.** Пока подключение приложения не поднято, его
  соединения отклоняются, а не идут мимо VPN. Это держится и тогда, когда
  служба остановлена.

Для своих подключений нужен установленный
[OpenVPN](https://openvpn.net/community-downloads/) (программа запускает
его `openvpn.exe` и пользуется его адаптерами TAP).

## Установка

Скачайте `vpnsplit-setup.exe` со страницы
[выпусков](https://github.com/klyakssa/vpnsplit/releases/latest) и
запустите. Установщик попросит права администратора: программа ставит
службу Windows. Файл не подписан сертификатом издателя, поэтому Windows
при первом запуске покажет предупреждение SmartScreen.

Удаление — через «Программы и компоненты». Настройки остаются в
`C:\ProgramData\vpnsplit` (там же сохранённые конфиги VPN с паролями) —
удалите эту папку, если они больше не нужны.

## Обновления

**Программа обновляется сама и без вопросов.** Раз в шесть часов служба
смотрит, нет ли на этой странице GitHub выпуска новее, скачивает
установщик и ставит его; служба при этом перезапускается на несколько
секунд.

Чужой файл так не поставить: описание каждого выпуска подписано ключом
автора, которого на GitHub нет, а в программу вшита его открытая половина.
Служба проверяет подпись, номер сборки (старее нынешней не ставится) и
SHA-256 установщика; если новая служба не запускается, установщик
возвращает прежнюю.

Отключить обновления: создайте пустой файл
`C:\ProgramData\vpnsplit\no-update`. Что служба думает об обновлениях:
`vpnsplit-svc update`; что сейчас лежит на GitHub: `vpnsplit-svc update look`.

## Как это устроено

- `vpnsplit-svc` — служба: список приложений, свои подключения, перехват.
- `vpnsplit-ui` — окно и значок в области уведомлений.
- Перехват идёт через драйвер [WinDivert](https://reqrypt.org/windivert.html):
  у пакетов выбранных приложений адрес отправителя заменяется адресом
  туннеля, и Windows отправляет их в туннель. Имена (DNS) приложений из
  списка тоже уходят в туннель.
- `vpnsplit-launch` и `vpnsplit_hook.dll` — второй способ, для отдельно
  запущенной программы: её сокеты привязываются к туннелю.

IPv6 не поддерживается.

## Сборка

Нужен [Rust](https://rustup.rs/) (stable, цель `x86_64-pc-windows-msvc`).

```
cargo build --workspace
cargo test --workspace
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\make-setup.ps1
```

Последняя команда собирает `dist\vpnsplit-setup.exe`. Такая сборка — «для
разработки»: сама она не обновляется. Выпуски делает
`scripts\make-release.ps1`, ему нужен ключ автора
(`scripts\new-release-key.ps1` создаёт свой — для своей ветки программы со
своим адресом выпусков).
